<h2 align="left">🚀 Featured Projects</h2>

Here are some of the passion projects I've built and maintained:

- **[Vaultaria](https://github.com/JuanJoboy/Vaultaria)** – A modular **Terraria game mod** written in **C#** that has welcomed **12,500+ unique visitors**. Built utilizing clean object-oriented programming (OOP) and iteratively updated using Agile principles driven by player community feedback.
- **[Food Files](https://github.com/JuanJoboy/FoodFiles)** – A cross-platform dining-log **Flutter mobile app** backed by **Supabase** and **PostgreSQL**. Features secure user authentication via **OAuth**, interactive mapping utilizing the **Mapbox API**, and custom searchable food catalogs.
- **[Calorie Calculator](https://github.com/JuanJoboy/Calorie-Calculator)** – A lightweight health and nutrition tracking **Flutter app** featuring custom metabolic calculators, an interactive weekly scheduler, and offline local data storage using **SQLite**.
